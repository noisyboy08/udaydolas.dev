## Overview

Renders a full-screen `<canvas>` overlay that listens to `mousemove` events and spawns short-lived particles at the cursor position. Each particle drifts outward, shrinks, and fades, creating a magical cursor trail effect.

## Usage

```tsx
import { ParticleCursor } from "@/registry/particle-cursor";

export default function Layout({ children }) {
  return (
    <>
      <ParticleCursor
        colors={["#6366f1", "#a855f7", "#06b6d4"]}
        particleCount={6}
        particleSize={4}
      />
      {children}
    </>
  );
}
```

## Props

| Prop            | Type       | Default            | Description                                         |
| --------------- | ---------- | ------------------ | --------------------------------------------------- |
| `colors`        | `string[]` | indigo/purple/cyan | Colors randomly assigned to each particle.          |
| `particleCount` | `number`   | `6`                | Number of particles spawned per mouse move event.   |
| `particleSize`  | `number`   | `4`                | Initial radius of each particle in pixels.          |
| `lifetime`      | `number`   | `60`               | Number of animation frames each particle lives for. |
