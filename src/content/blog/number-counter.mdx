## Overview

Uses `IntersectionObserver` and `requestAnimationFrame` to animate a number from 0 to a target when the element enters the viewport. Supports custom value formatters, suffix strings, and easing.

## Usage

```tsx
import { NumberCounter } from "@/registry/number-counter";

export default function Demo() {
  return (
    <NumberCounter
      target={10000}
      duration={1500}
      formatValue={(v) => v.toLocaleString()}
      suffix="+"
    />
  );
}
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `target` | `number` | required | The number to count up to. |
| `duration` | `number` | `1500` | Animation duration in milliseconds. |
| `formatValue` | `(v: number) => string` | `String(v)` | Custom formatter for the displayed value. |
| `suffix` | `string` | — | Optional string appended after the number. |
| `className` | `string` | — | Extra class for the container. |
