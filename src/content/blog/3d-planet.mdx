## Overview

3D Planets Explorer is a visually stunning 3D space exploration experience built with React, Three.js, and GSAP. It allows users to explore Earth and 7 unique fictional planets with immersive animations, realistic textures, and smooth interactions.

![3D Planets Explorer Preview](/images/blog/3D planet .png)

## Key Features

- **🪐 Hyper-Realistic 3D Planets** - Rendered using Three.js and @react-three/fiber with custom shaders for atmosphere and terrain.
- **📊 Planet Statistics** - Detailed information cards with animated statistics for diameter, gravity, and surface area.
- **⚡ Smooth Scroll Animations** - Powered by GSAP ScrollTrigger for cinematic parallax effects and transitions.
- **☄️ Interactive Starfield** - A dynamic background starfield that reacts to mouse movement.
- **🖱️ Sleek Custom Cursor** - A space-themed custom cursor for enhanced interactive feel.
- **🚀 Cinematic Loading** - A full-screen loading sequence with progress tracking.

## Tech Stack

- **Framework**: React 18
- **Build Tool**: Vite
- **3D Rendering**: Three.js & @react-three/fiber
- **Animations**: GSAP (ScrollTrigger)
- **Styling**: Tailwind CSS
- **Smooth Scrolling**: Lenis
- **Routing**: React Router V6
