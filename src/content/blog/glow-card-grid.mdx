## Overview

Each card in the grid tracks the cursor and renders a radial gradient spotlight in the card's background and border, creating an interactive glow effect.

## Usage

```tsx
import { GlowCardGrid } from "@/registry/glow-card-grid";
import { SparklesIcon } from "lucide-react";

const ITEMS = [
  {
    title: "Motion Effects",
    description: "GPU-accelerated animations.",
    icon: <SparklesIcon className="size-4" />,
    glowColor: "#a855f7",
  },
];

export default function Demo() {
  return <GlowCardGrid items={ITEMS} cols={3} />;
}
```

## Props

### GlowCardGrid

| Prop | Type | Default | Description |
|---|---|---|---|
| `items` | `GlowCardGridItem[]` | — | Array of card data objects. |
| `cols` | `2 \| 3` | `3` | Grid column count on large screens. |
| `className` | `string` | — | Extra class for the grid container. |

### GlowCardGridItem

| Field | Type | Description |
|---|---|---|
| `title` | `string` | Card heading. |
| `description` | `string` | Card body text. |
| `icon` | `ReactNode` | Optional icon rendered above the title. |
| `glowColor` | `string` | Hex or CSS color for the glow spotlight. |
