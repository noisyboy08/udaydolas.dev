## Overview

A reusable feature highlight card with an icon rendered in a colored bubble, a title, a short description, and a subtle shimmer sweep animation on hover. Ideal for product landing pages and documentation.

## Usage

```tsx
import { FeatureCard } from "@/registry/feature-card";
import { ZapIcon } from "lucide-react";

export default function Demo() {
  return (
    <FeatureCard
      icon={<ZapIcon />}
      title="Instant Performance"
      description="Zero-config code splitting and edge deployment out of the box."
      accentColor="#6366f1"
    />
  );
}
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `icon` | `ReactNode` | required | Icon element shown in the colored bubble. |
| `title` | `string` | required | Card heading. |
| `description` | `string` | required | Short description text below the title. |
| `accentColor` | `string` | `#6366f1` | Background color of the icon bubble. |
| `className` | `string` | — | Extra class for the card wrapper. |
