## Overview

CAMS (Campus Activity Management System) is the ultimate operating system for college clubs and student organizations. It breaks away from boring spreadsheets and provides students with a vibrant, gamified, and highly interactive interface to manage memberships, balance financial ledgers, track event attendance, and automate announcements.

![CAMS Preview](/images/blog/campus club platform.png)

## Key Features

- **🪪 Next-Gen Digital Student E-ID** - Unique, dynamic student dashboard featuring animated card components, QR codes, and point achievements.
- **🤖 AI-Powered Copilot** - Uses intelligence to suggest tailored club event concepts, draft descriptions, and estimate attendance limits.
- **💳 Financial Budget Ledger** - Interactive expense tracking, digital wallet balances, and budget breakdown charts for student treasury officers.
- **🏆 Interactive Leaderboards** - Gamified user ranking system based on club meeting attendances and volunteer contributions.
- **📱 15+ Built-in Mini-Apps** - Full suite of micro-apps from resource booking systems to interactive voting polls.

## Tech Stack

- **Framework**: React 18, Vite
- **Language**: TypeScript
- **Database / Backend**: Supabase (PostgreSQL, Realtime subscriptions)
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion, Three.js (for 3D visual assets)
- **Deployment**: Vercel
