## Overview

Tracks mouse position relative to the card and renders a `radial-gradient` spotlight overlay that follows the cursor, creating a premium interactive card effect.

## Usage

```tsx
import { SpotlightCard } from "@/registry/spotlight-card";

export default function Demo() {
  return (
    <SpotlightCard spotlightColor="rgba(139, 92, 246, 0.15)">
      <h3 className="text-white font-semibold">Card Title</h3>
      <p className="text-zinc-400 text-sm">Hover to reveal the spotlight.</p>
    </SpotlightCard>
  );
}
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `children` | `ReactNode` | required | Card content. |
| `spotlightColor` | `string` | `rgba(139,92,246,0.15)` | Any CSS color for the spotlight radial gradient. |
| `className` | `string` | — | Extra class for the card wrapper. |
