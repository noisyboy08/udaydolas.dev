## Overview

A fully controlled tab bar with three visual variants. The active tab indicator slides smoothly between tabs using `layoutId`-based animation (Motion for React). Supports horizontal scrolling for many tabs on small screens.

## Usage

```tsx
import { AnimatedTabs } from "@/registry/animated-tabs";

export default function Demo() {
  return (
    <AnimatedTabs
      tabs={["Overview", "Features", "Pricing"]}
      defaultTab="Overview"
      variant="pill"
      onTabChange={(tab) => console.log(tab)}
    />
  );
}
```

## Props

| Prop          | Type                              | Default   | Description                                 |
| ------------- | --------------------------------- | --------- | ------------------------------------------- |
| `tabs`        | `string[]`                        | required  | List of tab labels.                         |
| `defaultTab`  | `string`                          | first tab | Initially active tab label.                 |
| `variant`     | `"pill" \| "underline" \| "card"` | `"pill"`  | Visual style of the tab bar.                |
| `onTabChange` | `(tab: string) => void`           | —         | Callback fired when the active tab changes. |
| `className`   | `string`                          | —         | Extra class for the tab bar wrapper.        |
