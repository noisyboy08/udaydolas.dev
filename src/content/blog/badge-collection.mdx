## Overview

A set of small pill-shaped badge components for displaying status labels, tags, and counts. Includes semantic color variants (success, warning, error, info), a neutral outline style, and a gradient option.

## Usage

```tsx
import { Badge } from "@/registry/badge-collection";

export default function Demo() {
  return (
    <div className="flex gap-2">
      <Badge variant="success">Active</Badge>
      <Badge variant="warning">Pending</Badge>
      <Badge variant="error">Failed</Badge>
      <Badge variant="info">Beta</Badge>
      <Badge variant="gradient">New</Badge>
    </div>
  );
}
```

## Props

| Prop        | Type                                                                     | Default     | Description                        |
| ----------- | ------------------------------------------------------------------------ | ----------- | ---------------------------------- |
| `children`  | `ReactNode`                                                              | required    | Badge label content.               |
| `variant`   | `"success" \| "warning" \| "error" \| "info" \| "outline" \| "gradient"` | `"outline"` | Color scheme of the badge.         |
| `className` | `string`                                                                 | —           | Extra class for the badge element. |
