## Overview

Renders a sequence of words one at a time, animating each swap with a `rotateX` flip using CSS `perspective` and `transform`. Ideal for hero headings that highlight different value propositions.

## Usage

```tsx
import { TextFlip } from "@/registry/text-flip";

export default function Demo() {
  return (
    <TextFlip
      words={["Fast", "Beautiful", "Accessible"]}
      interval={2000}
    />
  );
}
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `words` | `string[]` | required | The list of words to cycle through. |
| `interval` | `number` | `2000` | Milliseconds between each word swap. |
| `className` | `string` | — | Extra class applied to the text element. |
