## Overview

AI Travel Planner is a visually stunning travel planning web application that leverages artificial intelligence to build custom, curated travel itineraries based on user preferences. Featuring an interactive 3D Globe, real-time weather forecasts, and interactive destination routing, this platform makes travel planning immersive, intuitive, and modern.

![AI Travel Planner Preview](/images/blog/Ai Travel Plan .png)

## Key Features

- **🌍 Interactive 3D Globe** - A fully interactive 3D globe rendered with Three.js and React Three Fiber to select, rotate, and highlight travel destinations in real-time.
- **🤖 AI Itinerary Generator** - Harnesses the power of the Google Gemini API to dynamically build detailed, day-by-day travel itineraries based on destination, duration, and user interests.
- **🌤️ Glassmorphic Weather Dashboard** - Sleek, real-time weather insights utilizing the OpenWeather API to display current conditions and upcoming forecasts for any location.
- **🗺️ Destination Route Mapping** - Visual representation of travel paths and destinations on clean, customizable interactive maps.
- **🚀 Ultra-smooth Transitions** - A premium, fluid UX powered by Framer Motion, Tailwind CSS, and CSS-based glassmorphism.

## Tech Stack

- **Framework**: Next.js 15
- **3D Graphics**: Three.js, React Three Fiber, `@react-three/drei`
- **AI Integration**: Google Gemini API
- **APIs & Data**: OpenWeather API
- **Styling & Motion**: Tailwind CSS, Framer Motion
- **Deployment**: Vercel
