## Overview

A visually striking animated orb component that cycles through a custom color palette using layered radial gradients. Features three layers — outer glow, mid glow, and a core sphere with a specular highlight — for a realistic glass-like appearance.

## Usage

```tsx
import { GlowingOrb } from "@/registry/glowing-orb";

export default function Demo() {
  return (
    <GlowingOrb
      size="md"
      colors={["#6366f1", "#a855f7", "#06b6d4"]}
      speed={4}
    />
  );
}
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | Controls the orb size (80px / 128px / 192px). |
| `colors` | `string[]` | indigo/purple/cyan palette | Array of hex colors to cycle through. |
| `speed` | `number` | `4` | Seconds between color transitions. |
| `className` | `string` | — | Extra class for the container. |
