## Overview

Makes a client-side fetch to the GitHub REST API to retrieve the star count for any public repository and renders it in a compact pill badge. Uses SWR for caching and revalidation.

## Usage

```tsx
import { GitHubStars } from "@/registry/github-stars";

export default function Demo() {
  return <GitHubStars repo="noisyboy08/udaydolas.dev" />;
}
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `repo` | `string` | required | GitHub repository in `owner/repo` format. |
| `className` | `string` | — | Extra class for the badge wrapper. |
