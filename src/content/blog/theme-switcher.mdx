## Overview

A beautifully animated pill-shaped theme switcher. The active indicator slides smoothly between Sun, Moon, and Monitor using a shared layout animation.

## Usage

```tsx
import { ThemeSwitcher } from "@/registry/theme-switcher";

export default function Demo() {
  return <ThemeSwitcher />;
}
```

## Props

No props — the component reads and writes the theme via `next-themes` context.

## Requirements

- `next-themes` must be installed
- Wrap your app with `ThemeProvider` from `next-themes`
