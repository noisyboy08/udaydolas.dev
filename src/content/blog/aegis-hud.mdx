## Overview

Aegis HUD is a futuristic tactical defense dashboard built with React-Three-Fiber, Three.js, and custom GLSL shaders. It replicates a cyberpunk interface featuring an interactive force field control system, procedural starry background, node-based interactive telemetry, and a weapon grid.

![Aegis HUD Preview](/images/blog/Aegis HUB.png)

## Key Features

- **🛡️ Core Shader Tech** - Hexagonal grid fragment shader, force field shields, custom noise mapping, and dynamic post-processing effects.
- **📊 Interactive Telemetry Flowchart** - A node-based interactive flowchart mapping the defense network telemetry in real-time.
- **⚔️ Weapon Selection Chamber** - Interactive selection grid for cyberpunk weapons (plasma rifle, neon cutter, laser blade) with custom damage, fire rate, and range stats.
- **🎛️ Diagnostic Control Panel** - Real-time control panels for customizing shader post-processing, force field parameters, and grid colors.
- **🌌 Procedural Starfield** - A dynamic background star system that reacts to cursor movement.

## Tech Stack

- **3D Graphics**: React Three Fiber, Three.js, React Three Drei
- **UI Componentry**: React Flow, Tailwind CSS, Leva (Controls)
- **Animations**: Framer Motion
- **Build Tool**: Vite
- **Routing**: React Router V6
