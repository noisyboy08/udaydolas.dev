## Overview

Uses a `conic-gradient` pseudo-element with a CSS `@keyframes` rotation animation to create a continuously sweeping gradient border effect around any card content.

## Usage

```tsx
import { GradientBorderCard } from "@/registry/gradient-border-card";

export default function Demo() {
  return (
    <GradientBorderCard colors={["#6366f1", "#a855f7", "#06b6d4"]}>
      <p className="text-sm text-muted-foreground">Your card content here.</p>
    </GradientBorderCard>
  );
}
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `children` | `ReactNode` | required | Card body content. |
| `colors` | `string[]` | indigo/purple/cyan | Colors for the rotating conic gradient border. |
| `speed` | `number` | `3` | Full rotation duration in seconds. |
| `borderWidth` | `number` | `1` | Width of the gradient border in pixels. |
| `className` | `string` | — | Extra class for the outer wrapper. |
