## Overview

Renders a horizontal step progress tracker in one of three visual variants. The `numbered` variant shows connected circles with step numbers and labels; `bars` renders a row of fill-animated bars; `dots` shows a pill-shaped dot that expands for the active step.

## Usage

```tsx
import { StepProgress } from "@/registry/step-progress";

export default function Demo() {
  return (
    <StepProgress
      steps={["Account", "Details", "Payment", "Review"]}
      current={1}
      variant="numbered"
      accentColor="#6366f1"
    />
  );
}
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `steps` | `string[]` | required | Labels for each step. |
| `current` | `number` | required | Zero-based index of the active step. |
| `variant` | `"numbered" \| "bars" \| "dots"` | `"numbered"` | Visual style of the progress indicator. |
| `accentColor` | `string` | `#6366f1` | Color applied to completed and active steps. |
| `className` | `string` | — | Extra class for the wrapper. |
