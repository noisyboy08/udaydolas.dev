## Overview

CascadeAnnote is an advanced interactive codebase annotation tool designed to draw visual connections and highlight code blocks. Whether you are conducting code reviews, documenting architecture, or planning refactoring routes, CascadeAnnote lets you link files, add notes, and export configuration maps with ease.

![CascadeAnnote Preview](/images/blog/CascadeAnnote .png)

## Key Features

- **📝 Interactive Code Highlighting** - Select and annotate specific blocks of code inside an elegant, syntax-highlighted editor interface.
- **🔗 SVG Link Connections** - Draw clean, interactive vector lines directly connecting code components to visual annotation boxes.
- **🎨 Markdown Editor Pane** - Write rich documentation notes next to your code using markdown layouts.
- **💾 Export Configuration Sheets** - Export finished annotations as JSON files or shareable configurations.
- **⚡ Developer-First UI** - High-contrast themes, fast keyboard shortcuts, and a clean workspace design.

## Tech Stack

- **Framework**: React, Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide Icons
- **Transitions**: Framer Motion
- **Rendering**: SVG/HTML5 Canvas
- **Deployment**: Vercel
