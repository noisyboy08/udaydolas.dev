## Overview

Bakelpv is a fully responsive, high-end bakery experience built with Next.js 14 and Tailwind CSS. Tailored with custom wave dividers, floating food illustrations, and harmonious brand-consistent colors, it operates as a premium storefront showcasing catalog navigation, a cart reservation simulator, and table bookings.

![Bakelpv Preview](/images/blog/Bakelpv.png)

## Key Features

- **🍰 Beautiful Aesthetic Elements** - Floating cake illustrations, smooth SVG wave dividers, and custom animations that respond to scroll.
- **🛒 Dynamic Menu & Cart Flow** - Customers can search, filter, and sort delicious baked items, then manage quantities inside an active slide-out cart.
- **📅 Table Reservation Engine** - Interactive booking form complete with input validation and instant success states.
- **🔍 Global Search Overlay** - Slick, fast modal search overlay accessible from any page.
- **📱 Responsive Layout System** - Fine-tuned to render pixel-perfect designs from 320px mobile views all the way up to ultra-wide desktop monitors.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, CSS Variables
- **State Management**: React Context API
- **Animations**: Framer Motion
- **Deployment**: Vercel
