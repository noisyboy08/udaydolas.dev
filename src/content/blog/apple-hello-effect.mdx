## Overview

Recreate Apple's iconic "hello" handwriting reveal animation. The component traces SVG paths with smooth motion transitions, creating a satisfying pen-on-screen effect.

## Preview

The animation draws letter strokes sequentially with eased timing.

## Usage

```tsx
import { AppleHelloEnglishEffect } from "@/registry/apple-hello-effect";

export default function Demo() {
  return <AppleHelloEnglishEffect />;
}
```

## Props

| Prop                  | Type         | Default | Description                                     |
| --------------------- | ------------ | ------- | ----------------------------------------------- |
| `speed`               | `number`     | `1`     | Multiplier for animation speed. Lower = slower. |
| `onAnimationComplete` | `() => void` | —       | Callback fired when the last stroke finishes.   |
| `className`           | `string`     | —       | Extra class for the `<svg>` element.            |
