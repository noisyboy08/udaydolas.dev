## Overview

Wraps children in an `IntersectionObserver`-powered container that applies a configurable fade + translate animation when the element scrolls into view. Supports `up`, `down`, `left`, and `right` directions.

## Usage

```tsx
import { ScrollFadeEffect } from "@/registry/scroll-fade-effect";

export default function Demo() {
  return (
    <ScrollFadeEffect direction="up" delay={0.1}>
      <p>I fade in from below when scrolled into view.</p>
    </ScrollFadeEffect>
  );
}
```

## Props

| Prop        | Type                                  | Default  | Description                              |
| ----------- | ------------------------------------- | -------- | ---------------------------------------- |
| `children`  | `ReactNode`                           | required | Content to animate into view.            |
| `direction` | `"up" \| "down" \| "left" \| "right"` | `"up"`   | Direction from which the element enters. |
| `delay`     | `number`                              | `0`      | Animation delay in seconds.              |
| `duration`  | `number`                              | `0.6`    | Animation duration in seconds.           |
| `className` | `string`                              | —        | Extra class for the wrapper.             |
