## Overview

Comic Verse is an interactive digital comic community and catalog built for comic fans. Utilizing smooth page-turn animations, flexible tagging filters, reviews, and custom user reading histories, it forms a cohesive hub for comic book readers to explore, review, and track their favorite titles.

![Comic Verse Preview](/images/blog/COMIC VERSE.png)

## Key Features

- **📖 Interactive Page-Turn Reader** - Slick, immersive reading frame simulating realistic page transitions for digital viewing.
- **🔍 Filterable Catalog Hub** - Instantly search, filter, and categorise titles using tags, genres, ratings, or popularity metrics.
- **💬 Community Review System** - Interactive section where readers leave ratings, write reviews, and share comments.
- **👤 Custom User Profiles** - Dedicated dashboard for comic fans to bookmark reads, track statistics, and view personalized lists.
- **🎨 Premium Dark UI** - Modern cyberpunk-inspired dark theme featuring vibrant hues, glowing cards, and custom icons.

## Tech Stack

- **Framework**: React, Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Router**: React Router
- **Database / API**: Node.js & JSON API
- **Deployment**: Vercel
