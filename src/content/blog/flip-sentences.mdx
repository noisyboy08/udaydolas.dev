## Overview

Rotates through an array of sentences with smooth `y`-axis slide and fade transitions. Respects tab visibility — pauses when tab is hidden and resumes instantly when visible.

## Usage

```tsx
import { FlipSentences } from "@/registry/flip-sentences";

export default function Demo() {
  return (
    <FlipSentences
      sentences={[
        "Turning ideas into reality.",
        "Software Engineer.",
        "Tech Explorer & Innovator.",
      ]}
    />
  );
}
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `sentences` | `string[]` | required | Array of strings to rotate through. |
| `className` | `string` | — | Extra class for the `<p>` element. |
