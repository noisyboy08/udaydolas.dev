## Overview

Instead of truncating at the end like CSS `text-overflow: ellipsis`, this component removes characters from the middle of the string and inserts an ellipsis (`…`), keeping both the beginning and end of the value visible. Useful for file paths, hashes, and wallet addresses.

## Usage

```tsx
import { MiddleTruncation } from "@/registry/middle-truncation";

export default function Demo() {
  return (
    <MiddleTruncation
      text="0x742d35Cc6634C0532925a3b8D4C9B5a3Ef6C1d2"
      startChars={6}
      endChars={4}
    />
  );
}
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `text` | `string` | required | The full string to truncate. |
| `startChars` | `number` | `8` | Number of characters to keep from the start. |
| `endChars` | `number` | `4` | Number of characters to keep from the end. |
| `ellipsis` | `string` | `"…"` | String inserted at the truncation point. |
| `className` | `string` | — | Extra class for the span element. |
