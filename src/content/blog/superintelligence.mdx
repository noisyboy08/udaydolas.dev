## Overview

**Superintelligence** is an AI-First assistant platform built around a radical premise: the most advanced AI assistant should be **Private. Fast. Entirely Yours.** No data leaves your device. No cloud round-trips. No subscription surveillance. Superintelligence runs state-of-the-art language models directly on your local hardware using WebGPU acceleration — delivering on-device AI that rivals cloud performance while maintaining absolute privacy.

The platform serves as both a working AI product and a cinematic showcase landing page demonstrating what on-device superintelligence looks and feels like when built with zero compromise on design quality.

![Superintelligence Preview](/images/blog/Superintelligence.png)

## The Problem it Solves

Every mainstream AI assistant — ChatGPT, Claude, Gemini — sends every word you type to a server, logs your queries, uses your conversations for training data, and requires a paid subscription for meaningful usage limits. For sensitive work (legal, medical, financial, personal), this is an unacceptable privacy tradeoff. Superintelligence eliminates the tradeoff entirely: full LLM capability, zero data exposure.

## Key Features

### 🖥️ On-Device LLM Execution
Uses WebLLM — a cutting-edge framework for running quantized language models in the browser — combined with WebGPU for hardware-accelerated matrix computations. The model runs entirely on your local GPU. There are zero network requests after the initial model download. The downloaded model is cached in the browser's persistent storage for instant startup on every subsequent session.

### 🔒 Architectural Privacy Guarantee
Privacy isn't a policy — it's a technical constraint built into the architecture. The application has no backend server, no telemetry endpoints, no analytics SDKs, no session logging infrastructure. It literally cannot send your data anywhere because there is no server to send it to. The only network activity is the initial one-time model weight download from a public CDN.

### ⚡ GPU-Accelerated Token Generation
WebGPU compute shaders provide hardware-accelerated matrix multiplication operations — the core computation of transformer inference. On a mid-range consumer GPU (e.g., RTX 3070 or Apple M2), Superintelligence achieves 20-40 tokens per second, which is faster than most users can read — making the on-device experience feel instant and fluid rather than slow and limited.

### 🎨 Cinematic Scrolljacking UI
The landing page and onboarding experience is a full scrolljacking showcase powered by GSAP ScrollTrigger. Each section (Intro → About → Services → Work → Process → Voices → Pricing) has its own entrance choreography: 3D perspective card reveals on the "Work" section, staggered text cascade animations, an animated neural-grid background that responds to scroll velocity, and keyboard-driven arrow key navigation between sections.

### 🗣️ Multi-Modal Input Interface
Text (keyboard), voice (browser Web Speech API for speech-to-text input), and document context (drag-and-drop PDF parsing that extracts text into the model's context window) all feed the same local LLM session. This enables use cases like: "Summarize this contract PDF without sending it anywhere" or "Explain this medical report to me privately."

## Design Philosophy

Superintelligence's aesthetic is deliberately cinematic and minimal — a black canvas with a teal-green neural grid animation that pulses like a living brain. The typography is editorial: a high-contrast serif ("Superintelligence") paired with a flowing script italic ("on-device") creates typographic tension that feels both authoritative and intimate. Section navigation dots on the right edge give users orientation in the scrolljacking experience without cluttering the content.
