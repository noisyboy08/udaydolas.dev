## Overview

Morphs between an array of words by scrambling each character through random ASCII symbols during the transition window. Built on `requestAnimationFrame` for buttery-smooth 60fps animation.

## Usage

```tsx
import { MorphingText } from "@/registry/morphing-text";

export default function Demo() {
  return (
    <MorphingText
      words={["ENGINEER", "DESIGNER", "CREATOR"]}
      className="text-4xl font-bold text-white"
      interval={2500}
    />
  );
}
```

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `words` | `string[]` | required | Array of words to cycle through. |
| `interval` | `number` | `2500` | Milliseconds between transitions. |
| `className` | `string` | — | Extra class for the `<span>` element. |
