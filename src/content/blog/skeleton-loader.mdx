## Overview

A collection of skeleton placeholder shapes — card, text lines, and circle — with a CSS `@keyframes` pulse/shimmer animation. Use while content is loading to prevent layout shift and reduce perceived latency.

## Usage

```tsx
import {
  SkeletonCard,
  SkeletonText,
  SkeletonAvatar,
} from "@/registry/skeleton-loader";

export default function Demo() {
  return (
    <div className="flex flex-col gap-4">
      <SkeletonAvatar size="md" />
      <SkeletonText lines={3} />
      <SkeletonCard />
    </div>
  );
}
```

## Components

| Component        | Props                                       | Description                                       |
| ---------------- | ------------------------------------------- | ------------------------------------------------- |
| `SkeletonCard`   | `className?`                                | Full card placeholder with header and body lines. |
| `SkeletonText`   | `lines?: number`, `className?`              | N lines of text placeholder.                      |
| `SkeletonAvatar` | `size?: "sm" \| "md" \| "lg"`, `className?` | Circular avatar placeholder.                      |
