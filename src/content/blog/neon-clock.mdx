## Overview

A real-time digital clock using CSS `drop-shadow` for a neon glow effect. Updates every 500ms with a blinking colon separator and displays hours, minutes, seconds, and AM/PM.

## Usage

```tsx
import { NeonClock } from "@/registry/neon-clock";

export default function Demo() {
  return <NeonClock color="purple" />;
}
```

## Props

| Prop        | Type                                      | Default    | Description                    |
| ----------- | ----------------------------------------- | ---------- | ------------------------------ |
| `color`     | `"purple" \| "cyan" \| "green" \| "pink"` | `"purple"` | Neon glow color theme.         |
| `className` | `string`                                  | —          | Extra class for the container. |
