## Overview

Anti-Gravity-City (also known as Lord of Repo) transforms your dull, static GitHub repositories into a sprawling, interactive, 3D Cyberpunk City. Instead of a flat grid, code modules float at different altitudes connected by energy beams, making repo exploration and analysis deeply gamified, visual, and engaging.

![Anti-Gravity-City Preview](/images/blog/Anti-Gravity.png)

## Key Features

- **🏙️ 3D Code City Visualization** - Automatically maps code files to buildings where height matches line counts, and placement corresponds to import/export structures.
- **🛡️ Force Fields & Altitudes** - Visually groups related folders and files inside distinct interactive altitude circles and glowing barriers.
- **🤖 Gemini AI Chatbot** - Ask questions about your code architecture directly to an AI assistant fully integrated into the 3D control panel.
- **⏱️ Commit Timeline Time-Travel** - Scrub through git commits to watch the city rebuild itself line by line, demonstrating repository growth.
- **🎵 Procedural Synthesizer** - Immersive UI clicks, hums, and ambient synth tracks synthesized in real-time using the Web Audio API.

## Tech Stack

- **Framework**: React, Vite
- **3D Graphics**: Three.js, React Three Fiber, `@react-three/drei`
- **AI Integration**: Google Gemini API
- **Sound System**: Procedural Web Audio API Synth
- **Styling & Motion**: Tailwind CSS, Framer Motion
- **Deployment**: Vercel
