## Overview

A compact card for displaying a single metric with a label, value, optional trend percentage (up/down), and a colored accent bar or icon. Great for dashboard UIs and analytics views.

## Usage

```tsx
import { StatCard } from "@/registry/stat-card";

export default function Demo() {
  return (
    <StatCard
      label="Monthly Revenue"
      value="$12,400"
      trend={+8.2}
      accentColor="#6366f1"
    />
  );
}
```

## Props

| Prop          | Type               | Default   | Description                                                       |
| ------------- | ------------------ | --------- | ----------------------------------------------------------------- |
| `label`       | `string`           | required  | Metric label shown above the value.                               |
| `value`       | `string \| number` | required  | The primary metric value to display.                              |
| `trend`       | `number`           | —         | Percentage change (positive = up, negative = down). Omit to hide. |
| `accentColor` | `string`           | `#6366f1` | Color of the accent bar and trend indicator.                      |
| `icon`        | `ReactNode`        | —         | Optional icon displayed in the top-right corner.                  |
| `className`   | `string`           | —         | Extra class for the card wrapper.                                 |
